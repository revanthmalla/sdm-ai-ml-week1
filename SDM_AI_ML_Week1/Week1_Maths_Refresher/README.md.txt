Week 1: Maths Refresher

Objective-
To revise the mathematical fundamentals required for understanding Machine Learning.

Topics Covered-

1. Vectors – Vector definition, components, addition, subtraction, magnitude, and dot product.
2. Matrices – Matrix definition, types, operations, transpose, determinant, and inverse.
3.Probability – Basic probability, events, conditional probability, Bayes' theorem, expected value, and variance.
4. Gradient Intuition – Derivatives, gradients, gradient descent, and learning rate.

The PDF file contains explanations, mathematical formulas, and simple worked examples for each topic.
